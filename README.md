# Vicious Tribe

A static, multi-page website concept for **Vicious Tribe**, an illustrated collectible-art project. The site explores the project's visual identity through animated artwork, a character trait sampler, a scroll-driven gallery, and a character showcase.

## Project pages

- `index.html` — animated landing page
- `rarity.html` — interactive character trait sampler
- `road-map.html` — scroll-driven artwork gallery
- `team.html` — character gallery
- `tomb.html` — scroll-based illustrated story

## Built with

- HTML, CSS, and vanilla JavaScript
- Bootstrap 5.2 and jQuery
- Locally bundled animation and interaction libraries

## Run locally

No build step or package installation is required. From the project root, start a local web server:

```sh
python -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Serving the files over HTTP is recommended so that browser asset loading works consistently.

## Project status

This is a front-end concept and does not implement wallet connections, NFT minting, or a backend service.
